# AI 机器学习项目

## 项目结构

```
/home/user/ai/
├── data/
│   ├── raw/          # 原始数据集（上传到这里）
│   └── processed/    # 处理后的数据
├── models/           # 训练好的模型保存位置
├── notebooks/        # Jupyter notebooks
├── scripts/          # 训练和推理脚本
└── README.md
```

## 如何上传数据集

### 方法 1: 直接复制文件
将你的数据集文件放到 `/home/user/ai/data/raw/` 目录

### 方法 2: 使用命令行上传
如果你有本地文件，可以使用 scp 或其他工具上传到这个路径

### 方法 3: 从网络下载
我可以帮你用 wget 或 curl 下载公开数据集

## 支持的数据格式

- CSV (.csv)
- JSON (.json)
- 图片 (.jpg, .png)
- 文本 (.txt)
- 其他常见格式

## 开始训练

上传数据集后，告诉我：
1. 数据集的类型（分类、回归、图像、文本等）
2. 你想用什么模型（我会推荐轻量级模型）
3. 训练目标

我会帮你编写训练代码！
